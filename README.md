## Featured Projects

### 1. OrderFlow — Order Preparation & Warehouse Operations

**Domain:** Order Fulfillment · Barcode Workflows · ERP Integration

OrderFlow is an ERP-connected application designed to support order preparation and operational workflows.

**Business Problem**

Warehouse and operations teams need to identify orders, process scanned products, track preparation progress, and reduce the risk of inconsistent operations.

**Engineering Work**

- Barcode-driven order preparation workflows
- Integration with AKINSOFT Wolvox order data
- Order detection and synchronization through a bridge component
- Product-level preparation progress and operational feedback
- Transaction consistency and recovery-oriented workflow design
- Performance analysis and iterative interface improvements

**Project Stage:** Developed and tested through iterative validation. Further development is driven by operational feedback.

### 2. WolvoxOrderSplit — Enterprise Order Splitting

**Domain:** Order Management · Business Rules · Operational Workflows

WolvoxOrderSplit is a business application designed to support splitting and managing ERP orders while preserving operational consistency.

**Business Problem**

Businesses sometimes need to divide existing orders into separate operational groups without losing track of the original order, related records, or workflow state.

**Engineering Work**

- Order splitting and order-detail workflows
- Business-rule validation and duplicate-operation safeguards
- ERP-connected order processing
- Optional order photo management
- Browser-based access, including controlled external-device workflows
- Order presentation, printing, and release-candidate validation

**Project Stage:** Iterative development and release validation. No public production availability is claimed.

### 3. Patron360 — ERP Analytics & Management Platform

**Domain:** Business Intelligence · Enterprise Reporting · Data Integration

Patron360 is a web-based analytics and management platform designed for businesses using AKINSOFT Wolvox.

**Business Problem**

Operational ERP data can be difficult to interpret quickly. Decision-makers need clear, reliable information without directly working with the underlying database.

**Engineering Work**

- ASP.NET Core and React-based application architecture
- Read-oriented Firebird data integration
- SQL Server staging and analytics processing
- Scheduled synchronization with Hangfire
- Data verification and reporting reliability workflows
- Responsive executive dashboard development

**Technology Highlights:** .NET · React · TypeScript · Firebird · SQL Server · Hangfire

**Project Stage:** Active development. An initial verified sales-reporting capability has been implemented; broader analytics capabilities remain under development.

---

### 4. Tekmert ERP — Enterprise Application Development

**Domain:** ERP Systems · Business Processes · Reporting · Application Architecture

Tekmert ERP is an enterprise application project focused on business workflows and ERP data integration.

**Business Problem**

Enterprise users need accessible interfaces for navigating business information, viewing operational records, and carrying out structured workflows.

**Engineering Work**

- Enterprise application architecture and user interfaces
- Firebird-based ERP data access
- Reporting and record-detail workflows
- Screens for quotations, orders, and invoice-related processes
- Controlled development of complex business workflows
- Validation-driven integration design

**Project Stage:** Active development. Verified read functionality is available for selected workflows. Some native ERP write operations remain subject to additional validation and are not presented as production-ready.
